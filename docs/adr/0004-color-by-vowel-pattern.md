# 0004: Kolor oznacza układ samogłosek

- Status: przyjęta
- Data: 2026-10-29

## Kontekst

Wcześniej kolory przydzielano grupom rymów i resetowano je w każdym czterowersie. Te same samogłoski (`worki`, `ziomki`) miały wtedy różne kolory, a różne samogłoski czasem ten sam.

## Decyzja

Kolor wynika z układu samogłosek rymowych fragmentu kolorowego (K-02) i jest wspólny dla całego tekstu. Pierwsze 16 układów dostaje kolory z palety bazowej, kolejne kolory są generowane (K-04).

## Konsekwencje

- Czytelnik od razu widzi, że rymy z różnych grup brzmią tak samo.
- Długi tekst może mieć więcej niż 16 układów, a generowane kolory są mniej wyraźne (Q-08).
- Dwie grupy o różnych samogłoskach nigdy nie są łączone (W-04), żeby kolor zawsze znaczył jedno.
